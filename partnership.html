How a partnership ad gets made
1. Pick a winnerSort the table by views. Anything already run as an ad is marked, so you are only picking from fresh material.
2. Ask the creator for the codeSelect the videos, hit Copy request, paste it into that creator's Slack channel. The message lists each video with its own link so the codes come back paired.
3. Paste the code hereInstagram codes start adcode-, Facebook codes start fbadcode-. One code per platform post — a video on both needs both.
4. Launch, then tick it offUse the code in Ads Manager as a partnership ad. Come back, add the ad name and mark it live.
