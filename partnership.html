1. Pick a winnerSort the table by views, or narrow the window with the date filters. Videos we have already run or already asked about are flagged in the Status column. Those records only start Feb 2026, so read a blank as probably fresh rather than a guarantee.

3. Paste the code hereInstagram codes start adcode-, Facebook codes start fbadcode-. One code per platform post — a video on both needs both.
4. Launch, then tick it offUse the code in Ads Manager as a partnership ad. Come back, add the ad name and mark it live.
